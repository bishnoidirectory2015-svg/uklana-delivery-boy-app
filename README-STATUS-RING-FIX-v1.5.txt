Uklana Delivery Boy App v1.5

Changes:
1. One status button advances sequentially: Food Preparing -> Picked Up -> Out for Delivery -> Delivered.
2. Delivered order automatically moves to Done Orders.
3. Customer tracking updates because WooCommerce order status is updated through API.
4. No delivery-boy live GPS is shared with customer.
5. Order sound now uses normal phone ringtone category, starts at full MediaPlayer volume and loops until Accept/Forward.
6. Ringtone picker now shows phone ringtones instead of alarm sounds.
7. New notification channel v2 prevents old alarm-channel settings from being reused.

Requires API plugin v1.4 or newer.
